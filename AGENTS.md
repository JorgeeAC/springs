# Sound Springs Agent Instructions

Before making meaningful changes to this repository, read:

1. `docs/agent-guide.md`
2. `docs/session-handoff.md`
3. Any relevant document under `docs/skills/`
4. The relevant technical documentation under `docs/`

Sound Springs is a human-directed experimental project.

Agents are encouraged to research, implement, test, iterate, and document, but should not redefine the project's purpose or introduce speculative architecture.

For long autonomous work, follow:

`docs/skills/autonomous-pass.md`

For DSP changes, follow:

`docs/skills/dsp-change.md`

For architectural changes, follow:

`docs/skills/architecture-change.md`
